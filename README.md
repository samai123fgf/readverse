# ReadVerse

ReadVerse is a modern digital library and e-book platform that allows users to discover, read and manage books on any device.  
It is designed to make reading accessible, enjoyable and engaging for everyone.

## 🚀 Live Demo  
Check out the live version here: [ReadVerse](https://readverse-nu.vercel.app/)

## Features  
- Browse a curated catalogue of e-books across multiple genres.  
- Seamless cross-device reading with responsive design (smartphone, tablet, computer).  
- Interactive e-book reader with realistic page-turn animations.  
- Create and manage your personal library: save favourites, build reading lists.  
- Track reading progress and habits; get personalised book recommendations.  
- Secure user authentication system.  
- Admin/management features to handle book catalog (depending on the version).

## 🎯 Technology Stack  
- **Frontend:** HTML5, CSS3, JavaScript  
- **Styling:** Tailwind CSS  
- **Design:** Responsive layout ensuring optimal experience on all devices
